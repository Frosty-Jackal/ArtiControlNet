# ArtiControlNet Spec 8：帮助弹窗（新手引导）

> 目标读者：Claude Code（用于按本 Spec 进行 Spec Coding）与项目作者（FJ）。
> 一句话：给工作台加一个**「帮助」弹窗**——纯前端、零后端改动。顶部新增「帮助」按钮，随时可开关；每位用户**首次登录自动弹出一次**，用三张能力卡片讲清**文生图 / 图文生图 / 图片问答（打分·分析）**三种用法，每种配一句可直接照抄的示例，新手照着输入就能上手。
> 本 Spec 是 **Spec.md / Spec2~7 的增量补充**，不推翻原有架构。不新增任何接口，不改 prompts / agents / 数据库。

---

## 1. 功能目的

- **教会第一次登录的用户怎么用**：自动弹一次帮助弹窗，讲清系统定位与三种玩法，附可直接照抄的示例句。
- **留白探索感**：三种玩法之后收一句「更多神奇进阶功能等你探索」，不把新手框死在三招里，给好奇留个口子。
- **随时可再查**：顶部「帮助」按钮常驻，任何视图下点一下都能重新打开。
- **美观可开关**：紫色主题、淡入上滑动画的 overlay 弹窗；遮罩点击 / 右上 × / Esc / 「开始使用」四种方式关闭。

---

## 2. 决策记录（为什么这么选）

| 决策 | 选择 | 理由 |
|---|---|---|
| 帮助内容 | **前端静态文案写死** | 纯展示，无后端请求、离线可用、零接口；改动只需改组件 |
| 首次引导 | 登录后**按用户自动弹出一次**：`localStorage` 标记 `artcn_help_seen:<username>`，**弹出即标记** | 只打扰一次、不再骚扰；「帮助」按钮随时可再开；标记与 Spec3 历史键同模式、随浏览器走（换浏览器会再弹一次，可接受） |
| 弹窗形态 | overlay 遮罩 + 居中卡片（fixed 定位） | 不占聊天布局、不打断输入；打开时锁 body 滚动 |
| 关闭方式 | 遮罩点击 / 右上 × / Esc / 底部「开始使用」 | 满足「可开关」，四路都收敛到同一个 `close` |
| 入口位置 | 头部「帮助」按钮（`btn-clear` 样式），**所有登录用户可见、任何视图可用** | 帮助是顶层弹窗，与「我的作品 / 用户管理 / 数据统计」三面板**不互斥**，从面板里也能打开 |
| 打分能力 | **走既有图像问答（qa_image）**，不新增「打分」接口 | 「帮我打个分」只是问答的一种问法，后端已支持，无需改动 |
| 示例句 | 三种玩法各配一句**可直接照抄**的 prompt | 新手照着输入即可命中对应工具，学习成本降到最低 |

> 排除项：不做分步向导 / 走马灯 / 新手任务 / 页面元素高亮；不改登录页（帮助只出现在登录后的工作台）；帮助文案不做远程配置或后端下发。

---

## 3. 需求边界

### 范围内
- 头部「帮助」按钮（所有登录用户可见）。
- 每位用户首次登录（含启动校验通过、登录成功两个时机）自动弹出一次帮助弹窗。
- 弹窗内容：一句话定位 + 三张能力卡片（文生图 / 图文生图 / 图片问答），每张含示例句 + 卡片后的**探索提示** + 底部文件提示 + 「开始使用」按钮。
- 关闭：遮罩点击 / 右上 × / Esc / 「开始使用」，四种方式均生效。
- 打开弹窗时锁定页面滚动，关闭后恢复。

### 范围外（本 Spec 不做）
- 不新增任何后端接口；不改 `prompts.py` / `agents/` / `providers/` / `db.py` / `main.py`。
- 不做分步引导、新手任务、页面元素高亮、帮助中心独立页面。
- 不改登录页与登录流程；帮助按钮只在登录后的工作台出现。
- 不把帮助文案做成可配置 / 可远程下发（写死在前端）。

### 已知限制（写入本文档，避免误读）
- 首次引导标记存浏览器 `localStorage`：清除站点数据或换浏览器后，会再次自动弹出一次（与 Spec3 会话历史同寿命）。

## 5. 实现方案

### 5.1 组件：`frontend/src/views/HelpModal.vue`（新建）

- 根元素：`fixed` 全屏遮罩 `div.help-overlay`（`rgba(0,0,0,0.6)`，可加 `backdrop-filter: blur(2px)`），`@click.self` 关闭。
- 内部 `div.help-card`：`max-width: 560px`，`bg-surface` 底 + `border-color` 边框 + `radius-xl` + `shadow-lg`，`animation: slide-up`（已有 keyframes）。
  - 右上角 `×` 关闭按钮（`btn`，hover 变红）。
  - 标题「认识 ArtiControlNet」：复用 `.brand h1` 的紫色渐变文字样式。
  - 引导语一行（见 §5.4）。
  - 三张能力卡片 `div.help-card-item`：竖向堆叠（窄屏自适应），每张 = 标题行（emoji + 玩法名）+ 一句说明 + 「照着说」示例 chip（`bg-input` 底、`purple-200` 字、等宽字体，形似输入框，提示可直接照抄）。
  - 卡片之后一条**探索提示**（muted 小字，可加 ✨）：「以上三种只是基础玩法，更多神奇进阶功能，等你自己探索。」——承接卡片、留探索感。
  - 底部：文件格式提示（muted 小字）+「开始使用」按钮（复用 `.btn-primary`）。
- `onMounted` 给 `document.body` 加 `overflow: hidden`；`onBeforeUnmount` 恢复。
- 监听 `keydown.esc` → `emit('close')`；组件不做任何业务逻辑。
- 全部文案按 §5.4 字面写死，不引用变量 / 配置。

### 5.2 接入：`frontend/src/App.vue`

- 新增 `const showHelp = ref(false)`；模板根部（`.app` 内、三面板之后）挂载：
  ```html
  <HelpModal v-if="showHelp" @close="showHelp = false" />
  ```
- 头部新增按钮（**始终显示**，不随面板互斥逻辑隐藏）：
  ```html
  <button class="btn-clear" @click="showHelp = !showHelp">帮助</button>
  ```
- **首次自动弹出**：在现有登录态 watch（`[auth.loaded, auth.username]`）里，登录态就绪（`loaded && token && username`）且未打标记时自动弹出并打标：
  ```js
  const HELP_SEEN_KEY = (u) => `artcn_help_seen:${u}`
  // 在 auth 校验通过 / 登录成功的回调分支内：
  if (auth.token && auth.username && !localStorage.getItem(HELP_SEEN_KEY(auth.username))) {
    localStorage.setItem(HELP_SEEN_KEY(auth.username), '1')   // 弹出即标记，只弹一次
    showHelp.value = true
  }
  ```
  > 弹出即标记：即使未点「开始使用」就关掉，下次也不再自动弹（避免每次刷新都打扰）。

### 5.3 交互汇总

| 动作 | 行为 |
|---|---|
| 首次登录 / 启动校验通过 | 自动弹出（仅当该用户标记不存在）；随后写入标记 |
| 点「帮助」按钮 | 打开 / 关闭弹窗 |
| 点遮罩（非卡片区域） | 关闭 |
| 点右上 × | 关闭 |
| 按 Esc | 关闭 |
| 点「开始使用」 | 关闭 |

### 5.4 文案定稿（字面写死）

```
标题   认识 ArtiControlNet
引导   辅助设计的 AI 工作台——你说想法，它出图。三种玩法，照着说就行。

卡片一  🎨 文生图
       没有参考图？直接描述想要的画面，它生成一张新图。
       照着说：「做一张赛博朋克风的新年海报」

卡片二  🖌 图文生图
       文字 + 参考图。把设计线稿传上来，按你的要求上色、上风格。
       照着说：「按这张线稿上色，日系动漫风」

卡片三  🔍 图片问答
       传一张图问它：评价、打分、分析都行。
       照着说：「这张图怎么样？帮我打个分」

探索   以上三种只是基础玩法，更多神奇进阶功能，等你自己探索。
底栏   支持 jpg / png / webp / gif，≤10MB。每条消息都能带一张图。
按钮   「开始使用」
```

> 文案口径与系统能力一一对应：卡片一 ↔ `generate_image`；卡片二 ↔ `edit_image`（线稿上色 / 上风格）；卡片三 ↔ `qa_image`（打分、分析是问答的问法）。示例句可直接触发对应工具，验收见 §8。

## 8. 验收用例（端到端 Smoke）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 清空 `localStorage` 后登录（或全新用户） | 登录后自动弹出帮助弹窗，遮罩置灰、页面不可滚动 |
| 2 | 关闭弹窗 → 刷新页面 | 不再自动弹出（标记已写 `artcn_help_seen:<username>`） |
| 3 | 点头部「帮助」 | 弹窗打开；再点一次关闭 |
| 4 | 弹窗打开时分别：点遮罩 / 右上 × / 按 Esc / 点「开始使用」 | 四种方式都能关闭，且 body 滚动恢复 |
| 5 | 查看弹窗内容 | 引导语一句话 + 三张卡片（文生图 / 图文生图 / 图片问答），每张含「照着说」示例句；卡片后一条「更多神奇进阶功能等你探索」的探索提示；底栏有文件格式提示与「开始使用」按钮 |
| 6 | 照抄示例「做一张赛博朋克风的新年海报」发送（不带图） | 正常文生图（`generate_image`） |
| 7 | 上传线稿 + 照抄「按这张线稿上色，日系动漫风」 | 正常图文生图（`edit_image`），出图上色/上风格 |
| 8 | 上传图片 + 照抄「这张图怎么样？帮我打个分」 | 正常图像问答（`qa_image`），返回评价/评分文本 |
| 9 | 同浏览器切另一用户登录 | 也自动弹出一次；两个用户标记互不影响 |
| 10 | 在「我的作品 / 用户管理 / 数据统计」面板打开时点「帮助」 | 弹窗正常出现在面板之上（overlay 层级最高） |
| 11 | 后端重启 | 帮助功能不受影响（纯前端、零接口） |

> 验收时明确排除：分步引导、新手任务、页面高亮、帮助中心页面、后端接口、帮助文案远程配置。
